## About

Portfolio website highlighting my experience as a Software Engineer with expertise in:

## Features

- 🎨 Modern, clean design with character
- 🌓 Dark/Light mode toggle with localStorage persistence
- ✨ Smooth scroll animations and fade-in effects
- 📱 Fully responsive (desktop, tablet, mobile)
- ♿ Accessibility-friendly (respects prefers-reduced-motion)
- 🎯 Full-width layout utilizing screen space

## Tech Stack

- Pure HTML5, CSS3, JavaScript (no frameworks)
- Google Fonts (Space Grotesk, Inter, IBM Plex Mono)
- Intersection Observer API for scroll animations
- CSS Custom Properties for theming
- GitHub Pages for hosting

- **Experience**: Professional experience at MAQ Software and education at RIT

- **Contact**: Links to email, GitHub, and LinkedIn

## Local Development

Simply open `index.html` in a browser, or serve locally:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

Visit `http://localhost:8000`
